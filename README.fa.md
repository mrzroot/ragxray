# ragxray (رگ‌اکس‌ری)

> **دیباگر بدون نیاز به LLM برای تشخیص شکستن مرز Chunkها و نقاط کور بازیابی در پایپ‌لاین‌های RAG**

[English](README.md) · [اکس‌ری تعاملی و مستندات](https://mrzroot.github.io/ragxray/)

```bash
ragxray inspect docs/ --chunk-size 800 --overlap 100 --html report.html
ragxray probe docs/ --query "تنظیمات کش" --json
```
